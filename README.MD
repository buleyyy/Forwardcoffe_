# Forward Coffee

**Move Forward, One Sip at a Time.**

Forward Coffee is a coffee brand built around the idea of accompanying everyday journeys through quality coffee, simplicity, and meaningful experiences.

This repository contains the source code for the official Forward Coffee website, designed as an informational and brand experience platform.

## About the Project

The Forward Coffee website is designed to introduce the brand, communicate its identity, and provide visitors with useful information about coffee.

Rather than functioning as an online ordering platform, the website focuses on brand storytelling, product information, coffee education, and editorial content.

## Website Features

- **Brand Introduction** — Introduces Forward Coffee, its philosophy, and brand identity.
- **Product Information** — Presents the coffee products and their characteristics.
- **Coffee Knowledge** — Educational content covering coffee beans, brewing methods, coffee origins, and related topics.
- **Journal & Articles** — Editorial content featuring coffee insights, stories, and discoveries.
- **About Us** — Provides information about the brand and its background.
- **Responsive Design** — Optimized for desktop and mobile experiences.

## Getting Started

### Prerequisites

- Node.js
- npm
- Git

### Installation

Clone the repository:

```bash
git clone https://github.com/buleyyy/Forwardcoffe_.git
```

Navigate to the project directory:

```bash
cd Forwardcoffe_
```

Install dependencies:

```bash
npm install
```

### Running the Project

Check available scripts:

```bash
npm run
```

Run the development script configured in `package.json`.

Alternatively, open `index.html` using a local development server such as VS Code Live Server.

## Development Principles

The development of Forward Coffee follows several principles:

1. **Brand Authenticity** — Maintain a consistent and recognizable brand identity.
2. **Simplicity** — Prioritize clean layouts and intuitive navigation.
3. **Content Quality** — Deliver useful, relevant, and engaging coffee information.
4. **Consistency** — Maintain visual and content consistency across all pages.
5. **User Experience** — Ensure a smooth experience across different devices.

## Repository Guidelines

- Keep production source code and assets organized.
- Do not commit `node_modules` or environment files.
- Keep local AI reference materials outside the public repository.
- Use meaningful commit messages.
- Maintain consistency with the established brand guidelines.

## Commit Convention

| Prefix | Description |
